# 只测量错误，不测量状态

在QC中，我们把1个逻辑比特分散藏在3个物理比特里。
- 正确的状态：三个比特必须保持完全一致。要么全是 $\ket{000}$，要么全是 $\ket{111}$。
- 退相干错误：环境干扰了其中一个，把它偷偷翻转了（比如变成了 $\ket{100}$）。
  
正确的量子纠错测量（Parity Check / 奇偶校验）：只测量相邻两个比特的“差值”
- 问题 A：第一个比特和第二个比特，一样吗？（测量结果：不一样）
- 问题 B：第二个比特和第三个比特，一样吗？（测量结果：一样）
- 结论：第 1 个比特发生错误了
  
  

Question: 比较两个状态的时候不是在measure吗？
- 比较不会破坏叠加态：
  - 比较即Parity Check - 测量两个qubit是否相同
  - 无论系统实际上坍缩到 $\ket{00}$ 还是 $\ket{11}$，“相同”这个答案都是 100% 成立的。
  - 这时我们作为观测者，没有获得任何关于它是0还是1的新知识，所以这个叠加态完好、没有collapse。
- 真正越界的测量：问具体state的状态
  - 问：第一个qubit是否是0？
- 在量子芯片上，使用Ancilla Qubit（辅助量子比特）来完成操作
  - C先跟A互动：如果A是 1，C就翻转一下。
  - C再跟B互动：如果B是 1，C再翻转一下。
  - 最后，我们只测量C。
  - 如果A和B一样都是0或都是1），C就会被翻转0次或2次，结果还是原样。如果A和B不一样，C就会被翻转1次，结果发生改变。
  - 使用了**量子纠缠的特性**
  
    
Question：那C和A互动的时候，判断A是否是1不也是测量吗？
- **Quantum Measurement Problem**
  - “那C和A互动的时候，判断A是否是1不也是测量吗“ 在物理上叫”**量子纠缠**“。
  - WHY？
    - C和A互动的过程，通常让它们靠得很近，利用它们之间的微波脉冲（microwave pulse)或库仑力(Coulomb force)产生耦合(Coupling)，这个操作叫**CNOT gate**。
    - 如果是测量：A的信息必须被放大，**传递到宏观世界**（like numbers on the screen），这时entanglement collapse了。
    - 如果是C和A互动：C也是一个微观的量子，A没有向宏观世界泄露消息，只与C发生entanglement。
    - 当 A 是 $\ket{0}$ 和 $\ket{1}$ 的叠加态时，C 跟着它一起进入了叠加态。
      - 互动前：A 是（0 + 1），C 是 0。
      - 互动后：系统变成了 （A是0且C是0） + （A是1且C是1）。
    - 然后C和B互动：due to数学的干涉效应-interference effect（翻转0次或2次效果抵消），C脱离AB的关系，变回确定的状态（比如0）。
    - 最后，我们去测量c（真正的测量），结果永远都是0.而这里的测量不会对A或B的entanglement状态产生扰动。
