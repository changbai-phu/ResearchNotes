### Combinatorial Problem
- Combination: choosing from many possible arrangements. 
  - e.g., routes to visit 4 cities: 4!= 24 possible routes
  - As the base (n in n!) gets larger, the possibilities explode -- *combinatorial explosion*. 
- So combinatorial problem is to find the solution from an enormous discrete set (of all the possibilities).

 ### Combinatorial Search  
 - find a solution that **satisfies some condition**, not finding the best solution. 

### Combinatorial Optimization
- Take one step harder than combinatorial search, this is to find the **best** solution. 
  - e.g., finding the shortest path among all possible routes
